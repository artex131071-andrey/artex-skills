# Правила работы с artex-skills

- Пользователя зовут Андрей. Общение, документация и комментарии — на русском языке.
- Здесь хранятся общие навыки и переносимые инструкции. Проектные инструкции других репозиториев остаются в своих проектах.
- Канонические тексты навыков — `skills/<имя>/SKILL.md`; метаданные — соседний `meta.yaml`.
- Поддерживаемый сценарий Windows для Андрея — `install-windows.ps1` для Codex и Claude. Старый `sync-skills.ps1` сохранён для прежнего сценария Copilot/Claude.
- Общие инструкции: `instructions/codex/AGENTS.md` и `instructions/claude/CLAUDE.md`. Три базовых процесса Claude установщик добавляет из SKILL.md, не дублируй их в шаблоне.
- Установщик должен копировать физические файлы, поддерживать `-WhatIf`, сохранять прежние версии и отказываться от записи через junction/символические ссылки.
- Не добавляй авторизацию, историю диалогов, персональные runtime-конфиги и разрешения конкретных команд.
- После изменения установки обновляй README, `docs/WINDOWS.md` и CHANGELOG; проверяй скрипт на временном профиле.
- Для заметной работы применяй `project-intake`, для завершения — `docs-closeout`; `plan-and-wait` применяется по запросу пользователя.
