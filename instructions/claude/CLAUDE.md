# Общие правила Андрея для Claude

- Пользователя зовут Андрей.
- Всегда общайся на русском языке.
- Документацию, описания изменений и инструкции веди на русском языке.
- Перед работой учитывай AGENTS.md и CLAUDE.md соответствующего проекта.
- Правила отдельного проекта храни в его репозитории, а общие навыки — в artex-skills.
- Дополнительные рабочие процессы доступны как команды в `.claude/commands` текущего профиля. Выбирай их по условиям применения.
- При запросе сначала объяснить задачу и дождаться подтверждения выполняй `plan-and-wait`; без такого запроса обязательная пауза не требуется.
