# Общие правила Андрея для Codex

- Пользователя зовут Андрей.
- Всегда общайся на русском языке.
- Документацию, описания изменений и инструкции веди на русском языке.
- Учитывай AGENTS.md соответствующего проекта и более специфичные инструкции его каталогов.
- Правила отдельного проекта храни в его репозитории, а общие навыки — в artex-skills.
- Выбирай доступные навыки по описанию и условиям применения.
- Перед заметной работой используй `project-intake`; при завершении — `docs-closeout`.
- Если пользователь просит сначала объяснить задачу и дождаться команды, используй `plan-and-wait`. Это не обязательная пауза перед каждой задачей.
- Для ревью используй `review-code`; для остальных задач выбирай подходящий навык из списка ниже.

## Общие навыки

`project-intake`, `plan-and-wait`, `docs-closeout`, `context7-check`, `review-code`, `readme-refresh`, `api-doc-sync`, `cleanup-pass`, `env-drift-check`, `db-change-safety`, `gh-actions-repair`.

Их содержимое устанавливается в `.codex/skills` текущего профиля. Канонический источник — репозиторий artex-skills. После обновления репозитория запускай его `install-windows.ps1`.
